           Die Anwendung verwaltet Firmen, Geschäftsführer, Standorte und zugehörige Dateien.

== Systemübersicht

Das *Firma-Management-System* ist eine Webanwendung, die Unternehmensdaten zentral verwaltet.
Die Kernfunktionen umfassen die Pflege von Stammdaten (Firma), das Erfassen mehrerer Standorte, die Zuordnung eines Geschäftsführers sowie das Speichern von firmenspezifischen Dateien.

.Systemarchitektur
[plantuml, system-architektur, svg]
----
@startuml
package "Frontend" {
  [React App]
}

package "Backend" {
  [REST API]
  [GraphQL API]
  [Business Logic]
}

package "Datenbank" {
  [PostgreSQL]
}

[React App] --> [REST API]
[REST API] --> [Business Logic]
[Business Logic] --> [PostgreSQL]
@enduml
----

== Geschäftslogik und Datenmodell

Die Geschäftslogik bildet die zentrale Steuerung der Anwendung.
Sie validiert Benutzereingaben, verwaltet Beziehungen zwischen Entitäten und delegiert Datenzugriffe an die Repository-Schicht.

.Service-Klassen im Überblick
[plantuml, firma-services, svg]
----
@startuml
class FirmaService {
  + createFirma()
  + updateFirma()
  + deleteFirma()
  + addStandort()
  + assignGeschaeftsfuehrer()
}

class StandortService {
  + createStandort()
  + updateStandort()
  + deleteStandort()
}

class GeschaeftsfuehrerService {
  + createGeschaeftsfuehrer()
  + updateGeschaeftsfuehrer()
}

FirmaService --> StandortService
FirmaService --> GeschaeftsfuehrerService
@enduml
----

== REST-Schnittstelle

Die Anwendung stellt eine REST-Schnittstelle bereit, die CRUD-Operationen auf allen Entitäten unterstützt.

.Controller-Übersicht
[plantuml, rest-controller, svg]
----
@startuml
interface FirmaController
interface StandortController
interface GeschaeftsfuehrerController
interface FirmaFileController

FirmaController : +GET /firmen
FirmaController : +POST /firmen
FirmaController : +PUT /firmen/{id}
FirmaController : +DELETE /firmen/{id}
@enduml
----
