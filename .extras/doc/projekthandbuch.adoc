           Die Anwendung dient zur Verwaltung von Firmen, Geschäftsführern, Standorten und zugehörigen Dateien.

== Systemübersicht

Das *Firma-Management-System* ist eine Webanwendung zur Verwaltung von Unternehmensdaten.
Sie erlaubt das Anlegen, Ändern und Löschen von Firmen, inklusive der zugehörigen Geschäftsführer, Standorte und Unternehmensdokumente.

.Systemarchitektur
[plantuml, system-architektur, svg]
----

  [PostgreSQL]
}

[React App] --> [REST API]

[Business Logic] --> [PostgreSQL]
@enduml

== Geschäftslogik und Datenmodell

=== Überblick

Die Geschäftslogik kapselt die Kernfunktionen wie das Anlegen einer Firma, das Hinzufügen eines Standortes oder das Verknüpfen eines Geschäftsführers.

----
